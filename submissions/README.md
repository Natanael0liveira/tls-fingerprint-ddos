# Submission packages

[NOMS 2027](noms2027/README.md) is the current delivery. Its `latex/` directory is
a complete Overleaf project, while `article.pdf` is the locally verified PDF.

Edit the canonical manuscript in `papers/http-session-noms/`, then verify it
and refresh the delivery with `make submission`. The checksum and release
checks detect divergent source copies. Current PDFs and ZIP bundles remain
local build products.
