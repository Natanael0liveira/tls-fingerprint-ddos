# Post hoc analyses imported from the authors' handoff

Aggregate outputs are in `../../results/posthoc/`; `provenance.json` records
original hashes and portability/anonymization changes. No raw traffic or E5
timestamps/fingerprint identifiers are published.

| Script | Purpose |
|---|---|
| `bateria_f.py` | Rebuild false-alarm filters; replay for 1, 6 or 12 windows |
| `bateria_f2.py`, `bateria_f3.py` | Recurrence and follow-up collateral diagnostics |
| `bateria_f4.py` | Persistent-filter damage by endpoint |
| `fallback_por_endpoint.py` | Fallback exposure by endpoint |
| `regra_uniao.py` | Exact two-path union, including coverage |
| `strat.py` | Independence expectations by endpoint, time and window size |
| `holm.py` | Eight-test family and Holm adjustment from recorded aggregate counts |
| `hourly_compare.py` | Historical hourly-profile sensitivity; requires the corresponding experimental run |
| `e5_delay_modes.py` | E5 timing replay using a private input manifest |

Most scripts use `python script.py output.json`. Set `PRODDATA` to the operator
export directory, and `ENDPOINT_MAP` to a private JSON mapping real hostnames to
`E1`–`E4`. The required per-window CSVs are generated by the original evaluation
scripts. `holm.py` needs only SciPy/NumPy and prints its calculation.

E5 uses `python e5_delay_modes.py --manifest PRIVATE.json --out aggregate.json`.
Its docstring documents the private input schema. The manifest contains input
paths, the attack day and ordered windows for anonymous attack labels. Results
contain aggregate metrics only. The input schema retains the original export
column names, including the two attacker-label conventions.

The algorithms were ported from the handoff; restricted-data runs were not
reexecuted during this repository update. The aggregate files are recorded
outputs, not values manufactured from the manuscript. `hourly_compare.py` is
historical supporting code, not a required reproduction command for r53.
