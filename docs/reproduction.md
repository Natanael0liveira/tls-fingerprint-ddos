# Reproduction and data availability

## Submitted manuscript

The canonical source is [papers/http-session-noms/article.tex](../papers/http-session-noms/article.tex), recorded by tag `noms2027-submitted`. The [submission package](../submissions/noms2027/README.md) includes the complete LaTeX project, checksums and a source-bound verification record. Current PDFs are local build products.

All eight submitted tables are exported under `experiments/sprint-6-noms/results/manuscript/`. These files transcribe the manuscript and identify its source hash.

## Checks without operator data

```sh
make check
```

This runs the following Python standard-library checks:

```sh
python3 scripts/check_release.py
python3 scripts/export_tables.py --check
python3 experiments/sprint-6-noms/scripts/audit_paper.py
```

The release check verifies the submission checksums, synchronization with the canonical source and archived snapshot integrity. Both current PDF copies are checked when available; they may be absent in a public checkout. The table exporter covers all eight tables in source order. The numerical audit checks 217 cells against saved reductions and reports its omissions.

Use `make tables` to regenerate the current transcriptions and their audit record. Use `make submission` to refresh the delivery from source and PDF matching its verification record; a changed manuscript requires a new verification rather than relabeling an old result.

## Regression checks and figures

With the experimental Python environment installed:

```sh
make test
```

The six sustained-botnet regression tests use synthetic inputs. They check stable fingerprints, the legacy random stream, next-window activation, filter expiry, short-attack coverage, proportional cap exposure and rejection of invalid reconstructions.

For figure regeneration install `experiments/requirements-figures.txt`, then run:

```sh
python3 scripts/regenerate_figures.py --out build/figures
```

The two PNGs previously regenerated byte for byte with the pinned NumPy/Matplotlib versions. Building the current manuscript produced 11 pages with no overfull boxes or undefined references. Each text revision is rebuilt and checked against its own source-bound verification record.

## Recompute the prospective report

From the repository root, using the experimental environment:

```sh
experiments/.venv/bin/python experiments/sprint-6-noms/scripts/block_report.py --tables experiments/sprint-6-noms/results/production_tables_block.json --churn experiments/sprint-6-noms/results/ja4_churn_block.json --out /tmp/noms-block-report.json
```

The recorded prospective report was recomputed from those committed reductions and matched exactly. Its `test_days` section denotes the 14 prospective days, not the earlier development period.

## Restricted inputs and audit limits

Raw production exports, addresses and customer identifiers are not distributed. Original Makefile targets require the operator data drive (`PRODDATA`/`BLOCKDATA`) or generated scenario caches. Full dependencies are in `experiments/requirements.txt`; the existing experimental environment uses Python 3.11.

Saved generated-campaign summaries and anonymized operator reductions include `symbolic_detector.json`, `unseen_synth_summary.csv`, `production_tables.json` and `production_tables_block.json`. Post hoc handoff aggregates are in `experiments/sprint-6-noms/results/posthoc/`, with provenance hashes; their scripts are in the same experiment's `scripts/posthoc/` directory. E5 dates and selected fingerprint identifiers are omitted from public outputs.

The audit supports 217 numeric cells, including 24 primary E5 timing cells. It does not independently check every E5 alternative/FA cell, the two-path row, the E1-only footnote, the overview or every prose statistic. Six overview numbers and the novelty row's absence of false alarms were checked separately in the submission verification; the origin-cap numbers were not independently recomputed here.

The manuscript's persistence estimates use the original replay, which fixes a daily stack pool but redraws bot fingerprints each window. The corrected script defaults to fixed per-bot fingerprints and preserves the original model via `--assignment resampled`. No fixed-assignment production rerun was performed because the private exports were unavailable. See the [post hoc guide](../experiments/sprint-6-noms/scripts/posthoc/README.md).

Repository checks, figure generation, compilation and checks against saved reductions do not rerun the evaluation on restricted data. Cleanup does not create new experimental evidence.
