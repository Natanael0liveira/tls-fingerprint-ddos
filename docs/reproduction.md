# Reproduction and data availability

## Public artifact and private manuscript

This checkout distributes evaluation code, supporting figures and bibliography,
eight table snapshots and anonymized reductions. The complete manuscript and
upload project are omitted. [Submission metadata](../submissions/noms2027/README.md)
records the submitted-source hash, historical build checks and a separate ignored
local freeze. Earlier commits and the historical submission tag still contain
manuscript files; their removal from the current tree does not erase that history.

## Checks without operator data or a manuscript

```sh
make check
```

This runs Python standard-library checks:

```sh
python3 scripts/check_release.py
python3 scripts/export_tables.py --check
python3 experiments/sprint-6-noms/scripts/audit_paper.py
```

The release check verifies public artifact hashes and rejects full manuscript
files in the current paper/package directories. The exporter checks eight CSVs
against the committed `tables.json` snapshot. The numerical audit independently
compares 217 table cells with saved reductions and reports its coverage gaps.
These public checks do not compare the tables to an unavailable private TeX.

`make tables` regenerates CSV transcriptions and the audit record from the
committed snapshot. `make artifact` refreshes the public checksum manifest.
The historical `make submission` target aliases that operation and copies no
manuscript files.

## Optional checks against the private freeze

The authors' ignored snapshot is at
`archive/local/submitted/noms2027-2026-11-24/`. It preserves the exact submitted
TeX, a locally rebuilt PDF, build dependencies, original verification records,
the earlier complete snapshot and a self-contained Git bundle. Files have
read-only permissions and their hashes are recorded in the snapshot manifests.
On 25 November 2026 the author supplied the PDF identified as submitted to JEMS.
It is preserved separately in
`archive/local/submitted/noms2027-jems-confirmed-2026-11-25/`, bound to the
original freeze manifest by its hash. Extracted text and all eleven page renders
are identical to the local rebuild (RGB, 150 dpi). The supplied binary has its
own recorded hash. No independent portal access or submission receipt is claimed.

When that local snapshot is available, run from the repository root:

```sh
python3 scripts/check_release.py --private archive/local/submitted/noms2027-2026-11-24
python3 scripts/export_tables.py --check --source archive/local/submitted/noms2027-2026-11-24/paper/article.tex
```

The first command also verifies every private frozen file and the separately
sealed submitted-PDF confirmation. The second compares table transcriptions
with the frozen TeX and refuses a different source hash.
To restore the tag in another directory, follow the private snapshot's README;
keep new revisions separate from the frozen files.

## Regression checks and figures

With the experimental environment installed:

```sh
make test
```

The sustained-botnet regression checks use synthetic counts. They cover stable
fingerprints, the legacy random stream, delayed activation, expiry, short-attack
coverage, proportional cap exposure and invalid reconstructions.

Install `experiments/requirements-figures.txt`, then regenerate the two figures:

```sh
python3 scripts/regenerate_figures.py --out build/figures
```

The two PNGs previously regenerated byte for byte with the pinned dependencies.
The local manuscript build had 11 pages without overfull boxes or undefined
references; those are historical full-source checks recorded in the metadata.

## Restricted inputs and audit limits

Raw production exports, addresses and customer identifiers are not distributed.
Full experimental targets require the operator data drive or generated scenario
caches. Dependencies are in `experiments/requirements.txt`; the experimental
environment uses Python 3.11. See the [methodology](../experiments/METHODOLOGY.md)
for input paths and the [table guide](tables.md) for provenance.

The 217 checked cells include 24 primary E5 timing cells. The audit omits some
E5 alternative/FA cells, the two-path row, the E1-only note, the overview and
prose statistics. Six overview values were checked separately; cap figures were
not independently recomputed here. Public snapshots retain table-specific LaTeX
blocks and notes, not the full manuscript.

The persistence estimates use the original model: a fixed daily stack pool with
bot fingerprints redrawn each window. The corrected script defaults to fixed
per-bot fingerprints. No fixed-assignment production rerun was performed because
restricted exports were unavailable. See the [post hoc guide](../experiments/sprint-6-noms/scripts/posthoc/README.md).

Earlier metadata and development notes are indexed in [archive/](../archive/README.md).
None of these checks reruns the complete evaluation on restricted traffic.
