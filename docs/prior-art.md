# Positioning of the current manuscript

Table I compares what each approach selects, where it was evaluated and which question it addresses. It maps anomaly extraction, PacketScore, a JA3 mitigation report and this evaluation; it is not an experimental ranking.

The contribution evaluates when endpoint-relative fingerprint profiles permit selective filtering and how fleet activity, triggers and false alarms limit it. OWL, STIX and query compilation belong to the implementation history rather than the central contribution.

The study includes modal, z-score, novelty and history-based comparisons, plus an exploratory per-fingerprint origin cap. The cap challenges excess origins while the filters block selected fingerprints; the overview compares exposure to those distinct actions. The study does not benchmark a complete commercial WAF or establish superiority over selected-fingerprint challenges or prefix filters.
